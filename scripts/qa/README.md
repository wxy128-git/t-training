# 真实账号与教学质量验收

这些脚本不加入 `npm run check`，不应在 CI 中自动调用真实服务。

`teaching-cases.mjs` 为 19 个智能体各准备一个匿名、固定的教学任务和具体判据。先保留原提示词的输出，再针对实际问题修改并复测。评分维度见 `reviewRubric`；生成完成和格式正确不能代表教学内容正确。

真实验收使用独立的浏览器会话、临时 Firebase 测试账号和仅监听回环地址的候选 API。生产 Nginx、PM2 和发布目录保持原状。记录应说明使用的代码、模型、耗时、内容证据和未验证部分；不记录密钥、令牌、密码或真实学生资料。

模型请求默认关闭。获得具体额度许可后才启用，并把课程分类与供应商回退一并计入请求上限。账号、作品、订阅记录和临时服务在结束前清理；只保留匿名输出和验收结论。

`real-server.mjs` 只用于服务器独立的临时副本，读取既有私有环境配置，在 `127.0.0.1:18766` 运行实际 API；`.qa-control.json` 缺省允许 0 次模型请求，硬上限 32。临时账号限定 `ttqa-20260921-` 前缀及 `@example.invalid`，禁止恢复邮件投递；创建记录进入私有账本，日志不含密钥、令牌和密码。

本机经 SSH 转发后可使用 `node scripts/serve.mjs --port 18765 --api-origin http://127.0.0.1:18766` 测试流式响应。`--api-origin` 仅接受本机 HTTP 地址；不设置时继续使用原预览模式。浏览器验收应隔离会话并拦截统计写入和直接 Firestore 访问；邮件网络故障与支持邮箱配置用合成响应检查，不发邮件。

`cleanup-real.mjs` 仅处理账本中的测试数据，删除后逐条回查 Firestore 和 Authentication。可选 `--remove-staging` 只允许固定的本次服务器临时目录，并验证进程目录及启动命令后停止候选服务、删除临时副本。只有云端清理验证成功才移除账本。不要对生产目录运行这些脚本；迁移到其他验收日期时应一起更新账号前缀、目录守卫和额度许可。

本轮结果见 [验收报告](../../reports/2026-09-21-account-quality/README.md)：19 项基线、4 项复测，合计 23 次生成及 9 次分类；全部为 DeepSeek，未验证智谱。保存的匿名输出允许离线复核，不会自动产生新调用。
