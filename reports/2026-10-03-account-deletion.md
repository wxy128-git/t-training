# 注册异常账号删除（本地完成，尚未上线）

## 用户可见行为

后台用户列表新增“删除账号”。先显示姓名、账号、学校、备课本/投稿/其他关联内容数量；管理员输入显示的完整账号后才能提交。管理员自身不可删除。有作品的账号只显示数量并阻止删除，本轮不删除作品，也不提供强制删除。

删除成功后，同邮箱可以重新注册，新账号获得新的用户编号。旧手机号账号的资料和占用记录清除；当前注册仍要求真实邮箱，不恢复纯手机号注册。新账号不继承旧账号身份和旧本机草稿。

## 数据与安全边界

- 删除腾讯 `auth_users`、`user_profiles`、`auth_sessions`、`auth_action_tokens`，以及迁移表 `firestore_documents` 中同 UID 的 `users` 资料副本。
- 保留历史留言、历史统计记录和邮件订阅，删除窗口明确说明留言与记录保留；本功能用于释放异常账号，不代表清除所有历史个人信息。未执行历史数据清理或新增统计。
- 现有 `migration_meta` 表增加删除标记：键为旧 UID 的 SHA-256 摘要，值仅含删除时间，不存邮箱、手机号、密码或正文。不新建表、不改数据库结构。
- 使用数据库命名锁（防止同账号同时执行冲突操作）和事务（全部成功或全部撤回）。删除、Firebase 旧账号迁入及用户作品/留言写入共用同账号锁。提交删除时再次读取作品数量和账号资料。
- 删除确认凭据由服务器签名，绑定管理员、目标 UID、资料摘要，10 分钟过期。资料变化、作品增加、凭据过期或目标不符时拒绝删除。
- 正常登录方式和固定管理员 UID 规则不变。仅在旧 Firebase 迁移入口检查删除标记；旧密码及旧刷新令牌不能迁回已删 UID。旧 Firebase 邮箱链接也不能更改同邮箱新建腾讯账号的密码或验证状态。
- 腾讯端阻止旧账号恢复，不调用 Firebase 删除服务。`functions/api/admin-users.js` 标明旧路径停用；新预览/确认流程不兼容该旧接口，不自动回退。Firestore Rules 无需修改或发布。以后若回退旧服务，必须保留删除标记校验，不能直接恢复忽略该标记的旧迁移代码。
- 已经打开的页面可能仍显示旧姓名，但删除完成后的受保护请求会被拒绝；没有增加跨设备推送退出机制。

## 本地自己点验

在项目目录运行 `npm run preview:admin`，打开 http://127.0.0.1:8768/admin ，进入“用户列表”。

1. `teacher@example.invalid` 是无作品虚构账号：核对后输入该邮箱并确认，列表应移除该账号。
2. `author@example.invalid` 有一条虚构备课本：核对窗口显示数量，不能删除。
3. 演示管理员没有删除按钮。

重启演示会恢复虚构数据。结束按 Ctrl+C。无需真实登录凭据。
