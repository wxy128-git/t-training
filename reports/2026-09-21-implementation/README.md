## 验证结果与边界

- `npm run check`：站点结构检查覆盖 11 个公开页面、13 个应用页面；13 个课程匹配场景、66 项函数断言、19 项生成可靠性断言、8 项腾讯云适配断言全部通过，共 106 项自动回归场景 / 断言。
- 新增回归覆盖账号 A/B/访客隔离、旧共享草稿不自动归属、搜索匹配、流完整性、长度截断、断线、取消上游、首响应和流间隔超时；函数回归增加邮箱登记认证/去重/权限失败、页面文案缺省与工具元数据。
- 浏览器：1440×1000 桌面、390×844 手机；19 个智能体工作区均可打开，所测页面无整页横向溢出，无捕获的页面 JavaScript 异常。
- 合成接口验证了：重复点击仅发一次请求；失败保留手工编辑；账号隔离与切回恢复；断流阻止完整保存且刷新后仍标记未完成；停止后解锁且迟到响应不覆盖；备课本另存保留原稿、按所选版本继续；仅改标题也识别未保存；退出清空弹层，重新登录可恢复本机修改。
- 座位键盘交换、白板 10 个按钮名称、访客学习步骤与提示词复制、任务搜索、工具去重、后台元数据字段、文章单一主标题、教师资讯 1 条 / 综合 2 条的合成筛选、多模态主入口均通过。
- 多模态列表首次加载观察到波形 JSON 请求，没有 MP3 / MP4 请求。此结果说明消除了该预加载路径；不等同于真实移动网络性能百分位或 Lighthouse 得分。
- 腾讯云白名单打包检查包含 105 个静态文件、11 个 API 文件，新增脚本和波形均包含，报告、密钥与临时 QA 数据不进入发布包。
- 浏览器使用隔离的合成登录身份、作品、RSS 和模型响应；真实 Firebase 权限、真实模型质量/计费及生产网络流式传输仍需获准发布后的受控验收。未写生产数据、未消耗真实模型额度。
