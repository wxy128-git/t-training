# 科研写作板块验收

状态：本地实施完成，候选模型冒烟与生产发布待验证。

## 实现与边界

- 独立 `/research`，研究问题漏斗与文献精读卡两种工作台、卡片夹筛选与 CSV / Markdown 汇总；首页、导航、PWA、备课本续接、sitemap 和 SW 同步接入。
- 严格保留方案两个系统提示全文。后端唯一改动为 GLM 优先名单增加两个科研 ID；不改数据路径、路由、数据库结构、Firestore 规则、SiteCopy 12 页、认证、管理员、邮箱验证或隐私政策。agents.html 仅更新公共脚本缓存参数，行为未改。
- 论文与 PDF 不入库存储；仅保存规范化卡片、研究问题和提取元信息。没有新增统计事件或恢复采集。生成中断保存部分显示、禁止不完整卡片保存；账号切换中止请求并清空内容。
- PDF.js 固定为 [Mozilla 官方当前稳定版本 6.4.299](https://github.com/mozilla/pdf.js/releases/tag/v6.4.299)，从官方 npm 包取 legacy 主文件、worker 与 Apache-2.0 许可证。仅懒加载，legacy 提供兼容层但仍需要支持 ES modules 的浏览器；不将 ESM 文件声称为支持完全无 ESM 的 Safari。
- CSV / TSV 为防 Excel 公式执行，对以 =、+、-、@ 开头的值加文本前缀。OG 暂复用方案允许的 agents.jpg；不新建付费额度、画像或 v2 工具。

## 真实模型冒烟

候选 `127.0.0.1:3002` 上执行初次漏斗与真实 PDF 卡片各一次；发现质量偏差后，按 8.3 的“调提示词再测”复测一次，另对漏斗定向复测一次。总计 23 个模型请求（3 次漏斗完整流程各 7 次、2 次卡片各 1 次），均为 DeepSeek，响应头模型配置名 `deepseek-v4-flash`；服务器未配智谱，因此不声称验证了 GLM。接口未返回 token / 账单用量，报告不虚构精确扣费。

- 首测：漏斗 5 次追问后聚焦、再生成五标题，但同一主题里附带多个问句；精读卡一次 JSON 解析成功，但将未明确核心属性的 CHI 会议论文判为“核心”。
- 保留方案原始 system 字符串逐字不变，新增 `requestSystem` 补充约束：追问整轮一个短句、一个问号、禁止并列选项与多项条件；核心属性未写明必须未知，会议名注明会议论文，依据位置不贴长段原文。页面使用此请求版本。
- 卡片复测：10.975 秒完成，JSON 一次解析成功、补默认警告 0，核心属性为“未知”、会议信息正确。真实论文为 [ERIC 收录的数字同伴反馈研究（ED662172）](https://files.eric.ed.gov/fulltext/ED662172.pdf)，11 页正文在浏览器内提取完整。
- 最终漏斗：5 次追问均只含一个短问句，无建议，接着聚焦，再输出五种标题；两处固定标记完全一致，标题表格解析出 5 项；总响应耗时约 8 秒（不计教师回答），未超 6 轮追问。追问的质量仍需教师判断，例如模型有一轮询问教师希望先聚焦哪方面，不声称机械地执行了六个维度的理想顺序。
- 真实 `works`：临时普通账号（虚构无收信地址，无邮件）保存/读取两类成果、读取 `_card`、删除/回查 0 均通过。每次冒烟 finally 清理临时作品、账号、资料与会话；没有删除真实用户或改变数据库结构。
- 原始论文及完整提取文本仅为临时测试材料，任务末清理；保留的 [模型冒烟记录](2026-10-06-research-smoke.json) 只含合成漏斗对话与解析/耗时/清理摘要。
