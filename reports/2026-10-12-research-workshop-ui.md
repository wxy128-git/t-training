# 研究工具工坊界面重设计验收

日期：2026-10-12。状态：**本地完成，未部署、未推送**。

## 设计与实现

使用共享 `frontend-design` 技能。针对教师起草、逐条打磨研究工具的任务，采用左侧任务简报、右侧编辑文稿；手机按填写、结果顺序排列。沿用本站冷灰 `#f3f6f8`、白色、深墨 `#17212b`、正文 `#3d4a57`、结构蓝 `#245b78`、审查建议绿 `#287a68` 和品牌主按钮，系统中文字体，左对齐。将工具条目和审查对照作为主要视觉结构，减少重复标签。

- 工具类型改为带图标的三个选择块；从零起草、审查草稿明确分开。导入设计按需展开。
- 核心问题与填写 / 受访 / 观察对象分别成组。观察场景保留在必填区域；问卷维度、量表、访谈形式 / 时长、取样等设置默认折叠。小学低年级自动切换 3 点后的提醒直接显示在对象区域。
- 桌面简报和结果分别滚动，按当前可用视口高度调整；生成 / 保存操作保持可见。低高度桌面恢复页面自然滚动。
- 结果分为“编辑内容、审查建议、使用与检查”，展示条目、未处理建议和检查提醒数量，支持方向键、Home / End，面板具备可访问名称和焦点。
- 反向题、观察记录方式、等级标准放在所属条目内；维度定义与来源按需展开。维度改名同步条目分组及新增按钮。
- 审查从七列表格改为逐条原句 / 建议对照，手机上下排列。可以采用、定位或回到对应建议；已改写原句的过期建议不能采用，已删除条目不再提供定位按钮。
- 预览保留在结果标题旁，展示未保存的编辑；保存、重新审查、打印集中在底部，复制 Markdown / TSV 和重新生成按需展开。生成立即展示进度，结果区增加停止按钮；中止保留错误与重试入口。
- 说明备注继续使用悬停 / 聚焦 / 点击提示。新增 7 项可编辑界面文案，科研后台字段从 293 增至 300，腾讯上限仍为 300、其他页面仍为 40；兼容 Firestore 规则源同步。
