# 科研伙伴备注、阅读稿与预览验收

## 实施范围

按用户 2026-10-08 要求，使用 frontend-design 技能实施。设计与覆盖边界见 `docs/2026-10-08-research-reading-ui.md`。

- 两位伙伴工作页的介绍、开场说明、文献格式、隐私、重做与未保存说明改为备注符号。支持悬停、键盘聚焦、点击 / 触屏、Escape 关闭；长备注可滚动，弹层限制在视口内。错误、进度与字数仍直接显示。
- 十栏精读卡改为文献信息头部加九个阅读章节。数组、明确分隔的条目分点，栏目、明确标签及模型已有重点加粗；依据在对应栏目备注查看。右侧工作区独立滚动，顶栏保留预览。
- 教练已完成回复、聚焦结果及标题提供预览；精读卡预览包含当前未保存的改写，支持复制 Markdown。未完成 / 非结构化生成不能作为完成卡片保存。退出 / 切号清空预览。
- 后台“页面文案 → 科研写作”共 153 项，分六组；覆盖角色、开场、操作、状态、输入提示、备注、栏目、预览与常见失败反馈。新字段缺失时回退默认值，已有自定义字段保留。
- 腾讯保存上限仅科研扩至 160 项，其他页仍 40 项；超限 / 非字符串 / 超长字段整次拒绝，禁止截断。Firestore 兼容规则源同步显式字段及长度，未发布旧库规则。

## 验证

`npm run check` 全绿：函数 80、腾讯适配层 16、腾讯后台 42、科研 81 项；其余课程、邮箱、邮件构造、生成中断、资源、权限、隐私与账号删除回归通过。

浏览器插件初始化被宿主禁止的模块导入阻止，改用独立无头 Chrome 与临时本机服务。页面使用真实 HTML / CSS / Markdown 清洗 / 前端 DB 调用，身份和模型响应为虚构夹具；后台写入通过实际腾讯处理器与模拟 SQL。未读取浏览器个人资料或消费模型额度。

浏览器首轮 42 项通过：备注可访问性、模态备注边界、分节 / 分点 / 加粗、未保存改写预览、复制与结构化保存、全文不保存、格式失败、教练即时发送和预览、退出清空、153 项后台完整保存、迟到文案不覆盖输入、320 / 390 / 768px 边界与安全渲染。最终定向回归 46 项通过，增加独立滚动、明确字段标签加粗、后台状态文案同步及手机进度文字可见性。真实隔离数据库结果待补。

模型提示、科研 ID、卡片 JSON 结构与 CSV / TSV 19 列保持兼容。新保存的 Markdown 为分节稿；旧卡不批量重写。此次只改呈现与编辑文案，沿用已完成的真实模型冒烟，没有新增付费模型请求、邮件或生产业务写入。研究采集仍关闭。
