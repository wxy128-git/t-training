# 科研伙伴阅读与备注呈现调整

用户 2026-10-08 授权实施：两位伙伴的说明收进备注，精读卡改善排版、提供预览，静态文案可后台编辑。本方案覆盖初版的三列表格呈现要求，保留模型提示、结构化数据与导出列契约。

## 设计计划与复核

- 色彩：纸面白 `#ffffff`、工作区灰蓝 `#f3f6f8`、正文墨色 `#17212b`、结构蓝 `#245b78`、主操作红 `#b64235`、阅读标记绿 `#287a68`。
- 字体：沿用站点中文系统无衬线；正文 16px / 1.85，栏目 17px，文献标题 24px。正文左对齐，控制阅读宽度，避免长横表。
- 布局：左侧材料与研究问题，右侧伙伴回复与连续阅读稿；预览单独展示当前结果。备注靠近对应操作和栏目。

```text
材料 / 问题       伙伴回复   [预览]
                 文献标题与作者
                 研究问题 / 情境 / 方法
                 观点与证据：逐项列表
                 我的研读：改写区
```

复核后选用连续分节阅读稿，避免十个同形卡片切碎文献。仅对原有数组、明确分隔的条目分点，保留内容顺序；加粗栏目、标签与模型已有 Markdown 重点，不臆造结论。错误、生成状态与缺失信息仍可见。说明改为悬停 / 聚焦 / 点击备注，支持 Escape 关闭和手机触控。

## 数据与验收边界

预览读取当前生成结果及未保存改写，不发模型请求；旧卡片、备课本续接与 CSV / TSV 19 列保持兼容。科研文案沿用 page_copy，单页上限仅科研扩至 160 项，超限整次拒绝，禁止静默截断；其他页面维持 40 项。同步 SiteCopy、后台自动表单、腾讯接口与 Firestore 兼容规则源，不发布旧库规则。

需验证：备注可访问性及越界、Markdown 安全、条目与重点、预览与改写同步、账号切换清理、生成失败不能保存、后台全部文案完整保存，以及无中断发布。
