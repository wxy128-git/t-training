# 注册、访问与功能使用来源（本地完成，待上线）

用户明确要求同时查看地理分布和访问渠道。本轮在独立运营汇总中增加这两个维度，不恢复研究采集或个人使用明细。生产配置、数据库和站点均未修改，未提交或推送发布。

## 后台入口与口径

后台 → 数据看板 → 用户来源。沿用近 7 / 14 / 30 / 60 / 90 天，支持全部功能、栏目、23 位智能体／科研伙伴、9 个课堂工具和 8 个多模态案例筛选。地区按国家／地区、省份／地区、城市切换；两张完整表展示注册成功、页面访问、功能打开、生成成功、生成失败、成果保存次数。

- 注册成功、生成成败与保存由服务端钩子累计，浏览器不能伪造这些计数。无效／重复注册不计；注册不是每个功能的转化量，仅在全部功能或首页与注册范围内显示。
- 功能打开分别累计智能体、课堂工具、备课本以及多模态案例／视频／音频打开。不能将不同操作相加当成人数或个人漏斗。
- 来源只从启用后累计；此前记录不补填。尚未启用、时间范围早于启用时显示未采集，不能当作真实零。首日明确为部分时段。
- 每个地区层级按记录次数显示前 20 项，其余汇入“其他地区（合计）”，各列合计完整保留。国家／地区、省份、城市均可为未知；VPN、校园网、移动网络会影响 IP 网络出口估算。
- 原每日注册 KPI 来自当前账号记录，删除账号后可能变化；新来源表是启用后的注册成功累计，两者不应强行对齐。

## 来源归类

浏览器读取入口网址和 referrer，仅发送固定渠道代码，不传原文。支持百度、必应、Google、其他搜索、微信、QQ、微博、抖音、小红书、哔哩哔哩、知乎、通用分享、其他外部网站和来源不可见／未识别。

固定 `utm_source` 优先，否则使用可见的外部来源域名。平台隐藏 referrer 时无法可靠区分直接访问和分享，统一标明“直接访问／来源不可见”，不猜测微信来源。后台展开说明给出分享链接示例：

`https://ai.teachailab.com/?utm_source=wechat`

也支持 `qq / weibo / douyin / xiaohongshu / bilibili / zhihu / share` 等白名单值。任意搜索词、推广文本及域名不写入运营表。原始查询和 hash 不发送到运营统计。

当前标签页的 `sessionStorage` 仅保存固定渠道类别和开始时间，最长 30 分钟，用于站内换页后的归类；没有 Cookie、用户／访客／会话编号或浏览器指纹。同一页面停留超过期限不反复续用原分享参数；关闭标签页后清除。禁用存储时仍正常使用网站，但跨页来源可能无法保留。

## 地区与数据库

官方离线 [ip2region](https://github.com/lionsoul2014/ip2region) 支持 IPv4 / IPv6。固定库提交、SHA-256 和许可证见 `server/geo-data/README.md`；查询客户端锁定 `ip2region.js@3.1.8`。两库约 47 MiB，只进入 API 白名单发布包，不进入静态站或 SW；查询在内存中完成，不调用外部地区 API，不发送 IP，不新增付费服务。

Node 适配层沿用 Nginx 最后一跳覆盖后的连接 IP，忽略浏览器伪造的 CF 地区头。IP 仅用于本次内存查询，不进入运营表或按 IP 的缓存；丢弃运营商。私有、保留、非法或查询失败统一未知。

新表 `operations_sources_daily` 仅包含 `day / action / feature / target_id / country / region / city / source / count`；`operations_state` 新增独立 `sourcesStartedAt`。复合主键原子递增、幂等初始化，无个人事件、IP、uid 或自由文字。来源写入失败不阻断原计数或业务。来源查询失败显示接口错误，不返回假零。汇总继续校验固定管理员权限；所有筛选和值参数化，动态 SQL 列只从代码白名单选择。

## 发布准备

本轮版本：auth / data / agent-stream / operations-policy / operations-analytics / privacy-policy 查询参数 `20261017-sources`，政策 `2026-10-17.1`，SW `20261017-v49`。隐私政策同步说明地区估算和固定渠道短时存储，研究仍关闭，注册不新增强制政策勾选。

另行获得生产发布授权后，按腾讯无中断流程保留完整备份、安装锁定依赖、候选验证，再切换正式；原 `T_TRAINING_OPERATIONS_ANALYTICS=1` 之外新增 `T_TRAINING_OPERATIONS_SOURCES=1`，默认 0。候选初始化只新增来源表及启用时间，不清理历史数据。回滚保留新表，关闭来源开关即可停止新来源写入，不影响原运营。停用后再启用的空档需人工标明，与既有运营汇总规则一致。

可重复本地演示：`npm run preview:operations` → `http://127.0.0.1:8768/admin` → 数据看板，全为虚构数据，停止后不保留。
