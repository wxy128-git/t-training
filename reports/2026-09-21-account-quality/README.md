## 真实账号验收

静态页面在本机运行，通过 SSH 隧道访问服务器独立临时目录中的候选 API，仅监听回环地址。服务端使用真实 Firebase；浏览器直接连接 Firestore 被阻断，以检验同源 API 路径。统计请求被测试环境拦截，避免污染生产统计。邮件发送未执行。

| 场景 | 实际结果 |
|---|---|
| A 从注册界面创建账号；B 创建第二账号 | 成功；普通用户不获得管理员权限 |
| 错误密码、正确密码登录 | 错误密码被拒绝；正确密码成功 |
| 不勾选“记住我” | 代理会话仅在 sessionStorage；刷新本页保持登录，新开独立标签页是访客 |
| 勾选“记住我” | 代理会话在 localStorage，另一存储位置没有残留 |
| 模拟本地令牌过期时间，再走真实刷新接口 | 获取有效令牌并更新到期时间 |
| A 创建云端原稿，再从备课本界面编辑另存 | 两个版本同时存在，新版记录原稿关联，原稿正文未改动 |
| 从新版点击“基于此稿继续” | 智能体加载选中的新版正文与标题 |
| 退出后 B 进入备课本 | 列表为空；B 尝试改名、删除 A 的作品均返回 403 |
| A、B 分别保存本机草稿并切换 | B 看不到 A 的草稿；A 登录后恢复自己的草稿 |
| A 重新登录并刷新 | 两个已保存作品都可读取 |
| A 对自己的新版改名、删除 | 成功；原稿继续保留 |
| B 首次、重复登记同一测试邮箱 | 两次都返回成功；没有放宽订阅集合读取权限 |

证据：[浏览器检查结果](browser-checks.json)、[云端版本截图](screenshots/cloud-work-version.png)。

注册、云端读写、身份校验和模型接口均为真实服务。恢复邮件失败反馈使用合成 502 响应；“已配置支持邮箱”的 mailto、预填账号和复制逻辑使用测试邮箱与模拟剪贴板验证，不能视为真实邮箱可收信的证明。

## 无需登录的账号帮助

- 登录弹层加入“找回账号”和独立求助面板；访客点击“联系我们”可直接到达。
- 输入手机号码或 `tel_…@xylaoshi.tel` 时显示人工核验说明，浏览器没有发送重置请求；服务端也拒绝这类占位邮箱的邮件恢复。
- 配置收件邮箱后，可复制邮箱或打开预填主题与账号的邮件草稿；页面不自动发信。

## 真实模型测试范围与额度

19 个匿名样例及判据在 [teaching-cases.mjs](../../scripts/qa/teaching-cases.mjs)。每个样例通过页面现有的 `buildUserPrompt`、`curriculumContext`、`callAgentAPI` 和实际候选 API 执行；没有绕过课程匹配规则。

服务器账本确认：**32 次供应商请求 = 23 次正文生成 + 9 次课程分类**。正文包括 19 次基线和 4 次复测。全部实际使用 `deepseek-v4-flash`；本轮没有覆盖智谱模型或真实供应商回退。硬上限为 32，没有追加调用。

23 次正文全部收到完整结束事件。基线 19 次端到端耗时为 1.472–11.094 秒，中位数 6.208 秒；该小样本不能代表高峰时段性能。完整生成不等于教学质量合格。

输入、最终系统提示词、课程信息、模型、耗时、原始输出保留在 [baseline.json](baseline.json) 与 [retest.json](retest.json)。没有保存密码、令牌或真实学生资料。

## 逐项内容检查

以下为逐份阅读后的人工判定，按事实正确、任务适配、实际可执行、输入约束、证据边界检查，不以格式或关键词出现代替内容判断。“本样例可用”只针对这一份输出。

| 智能体 / 样例 ID | 基线发现 | 本轮处理 |
|---|---|---|
| 教学设计 / lesson-primary | 5+10+12+8+5=40 分钟；平均分讲解正确。9 组的全员任务不够具体，圆形纸等准备条件没交代清楚 | 增加每人任务、材料准备和观察性目标；不再把义务教育课标套用于高中 |
| 课件大纲 / courseware | 10 页完整；颜色词和问候句型正确，配有互动建议。本样例可用 | 加入通用事实与约束核对 |
| 微课脚本 / micro-science | 时间轴共 180 秒，旁白约 514 个汉字；主因解释基本正确，但未明确南北半球季节相反，近日点与季节“并不同步”的表述不够准确 | 增加参照方向、关键反例和口播时长检查。季节依据参见 [NASA 科普说明](https://spaceplace.nasa.gov/seasons/en/) |
| 课堂导入 / hook | 有 5 种方案；出现“废话问题”“逼学生”等不适宜话术，并混用了火焰变化、振动等现象作为证据 | 要求尊重学生、组织发言与核对实验现象的解释边界 |
| 苏格拉底导师 / socratic | 用两个一样大的苹果引导比较，只问问题，没有直接公布答案。本样例可用 | 保留提问方式，加入证据边界 |
| 分层提问 / layered | 3 层各 3 问，有理解、运用和评价差异；实物比较与纯数值比较的条件仍可更明确 | 补充“相同整体”适用场景的要求 |
| 概念解释 / concept | 水流类比有对应关系，但没有明确类比局限；直接用增添电池举例缺少器材适配条件 | 强制说明类比局限、电荷与能量的区别及器材适配条件 |
| 课堂活动 / activity | 45 人=9×5、流程共 10 分钟；“每人 2 题”与材料“4+4 题”不一致 | 补充完整任务卡、答案及人数/题数/材料/评分的一致性要求；已复测，见下表 |
| 出题助手 / quiz | 恰好 5 题，答案正确；第 2 题要比较 7/10 与 3/5 并通分，超出用户限定范围 | 约束覆盖题干、选项和解题过程；复测通过本样例范围与答案检查 |
| 作业批改 / grader | 正确算出 5/6，并指出所给 2/5 参考答案错误；“主动尝试”“愿意表达”的判断没有充分依据 | 增加独立核对参考答案、区分错误步骤与认知原因的要求 |
| 作文评改 / essay | 引用原句存在；仅凭键入文本却给出字的结构与卷面建议，没有清楚说明无法判断原稿书写 | 要求说明书写判断边界，并区分微调示例与真实经历 |
| 组卷 / exam | 11 题，10+20+20=50 分；方程答案回代正确。第 6–9 题解为 4、4、4、12；应用题为笔记本 4 本、钢笔 6 支，以及单价 5 元、总钱数 19 元。本样例通过所列判据 | 保留结构，强化逐题验算和细目表核对 |
| 错题诊断 / diagnosis | OCR 缺字题正确暂缓诊断；却断言学生“不习惯画图、估算和验算”，补救练习未逐项附答案 | 要求原因作为假设、附核实方法和补救答案 |
| 家校沟通 / parent | 编造“课堂上表现还是不错的”“我暂时没有批评”等输入中没有的事实 | 移除必须先夸奖的要求，限制学生与教师行为依据；已复测 |
| 学生评语 / comment | 编造“再轻轻说出自己的意见”“直接合上本子”等具体行为 | 移除必须扩写具体场景的要求，限制动作、频率与结果推断；已复测 |
| 主题班会 / meeting | 环节合计 40 分钟，但仍让学生回想伤害经历；表演未提供自愿替代，结尾全员发言的时间安排偏紧 | 改为虚构情境、自愿参与、替代任务并估算发言时间 |
| 谈心顾问 / heart | 没有把三天不举手直接判断为抑郁症；但将心理教师与医疗诊断混在一起，还从课后聊天推断较多 | 强化观察与诊断边界、开放询问。关于诊断应由合格专业人员评估的依据参见 [NIMH](https://www.nimh.nih.gov/health/publications/depression) |
| 教学反思 / reflection | 正确指出 8 人样本不能代表 40 人；但补造“操作感知”、具体讲解内容及小结成效 | 要求只依据实际记录，成功之处缺少证据时保留未知，改进措施配验证指标 |
| 听评课 / observation | 正文说明仅观察前 15 分钟；仍从提问 4 人推断“提问面较广”，补造注意力表现，总评又泛化为整课 | 要求记录、解释、建议分开，总评保留观察时段与证据边界 |

## 修改后的重点复测

| 样例 | 改善 | 仍需注意 |
|---|---|---|
| quiz | 5 题均为直接同分母或同分子比较；选择题答案 B、A、D，判断题正确、错误；选项唯一性和解析核对通过 | 单次通过不代表其他知识点均正确 |
| activity | 统一为每组 3 道匹配题、6 张卡；9 组共 54 张学生卡；9 组任务示例的答案正确，时间轴共 10 分钟 | 同时提供 12 分量规和可选 5 分简版，合作得分映射不清，教师仍需选定一种评分方式 |
| parent | 不再编造学生“课堂表现不错”，明确两次未交及原因未知 | 仍出现“先没有急着下结论”等代老师描述已有行为的措辞；发出前应删改或确认 |
| comment | 删除“写完就合上本子”等未提供的具体观察，检查作业改写为建议 | “大家更愿意和你一起学习”仍是未经输入证实的结果性推测，宜删去 |

这 4 项复测使用当前提示词。其余 15 项只完成基线阅读与规则调整，**没有对调整后输出再次调用真实模型**。本轮未突破额度增加第三轮生成。保留教师核验步骤，不能把提示词增强包装成自动保证内容正确。
